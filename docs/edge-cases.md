# Resuming and retrying

| What happened | What to do |
| --- | --- |
| You closed Codex before answering | Open the same chat and say “continue.” Fill in the restored question. |
| You restarted after submitting | Continue in the same chat. The saved answer can be used again. |
| You clicked Submit but did not receive confirmation | Retry the same answer. A retry does not create a duplicate. |
| You want to change a submitted answer | Ask for a new question. A second, different submission cannot replace the first. |
| The card reports a saving error | Resolve the disk or permission problem, then retry. |
| The card changed after an update, but the chat still stops | Reconnect the MCP server and invoke the skill again. |
| You deleted the chat or records, or more than 30 days have passed | Start a new questionnaire. |

Unsubmitted selections and text are not saved as drafts. Stay in the original chat when continuing; questions from other chats should not be used.

Inline cards and continuation after submission depend on the Codex client. A saved answer cannot start a chat turn that has already ended. When custom cards are unavailable, use a native question card or answer in the conversation.
